# Servidor Pokédex API (Express + TypeScript)

API intermedia construida con Node.js, Express 5 y TypeScript que consume la PokéAPI oficial, procesa los datos y expone endpoints limpios para el frontend.

## Requisitos Previos
* Node.js 18+ (utiliza `fetch` y `AbortSignal` nativos)
* npm
